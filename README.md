# ClassSense ML

ClassSense ML is a smart classroom analytics system that uses Machine Learning to analyze student behavioral data and classroom environmental conditions.

## Features

- Student Engagement Prediction
- Classroom Occupancy Level Prediction
- Random Forest-based ML models
- Environmental and PIR sensor analysis
- Manual input-based prediction
- Model performance evaluation
- Confusion Matrix visualization

## Model Performance

| Model | Purpose | Algorithm | Accuracy |
|---|---|---|---:|
| Model 1 | Student Engagement | Random Forest | 94.83% |
| Model 2 | Classroom Occupancy | Random Forest | 100% |

## Input Parameters

### Student Behavior
- Facial Expression
- Posture
- Class Subject
- Attendance
- Interaction Level
- Movement
- Heart Rate
- Skin Temperature
- Breathing Rate
- Student Noise Level
- Student Lighting
- Attention

### Classroom Environment
- CO₂ Average
- CO₂ Slope
- Room Sound
- Room Light
- Room Temperature
- PIR S6 Activity
- PIR S7 Activity
